# 학교 위치 검색창 구현 계획

## 목표

- `내 위치 보기` 버튼은 유지한다.
- 현재 상단 조작 영역의 흐름을 크게 바꾸지 않고 학교명으로 지도 중심을 찾을 수 있게 한다.
- 검색 결과는 실제 장소 기록으로 저장하지 않고, 지도 탐색을 돕는 임시 학교 위치 마커로 표시한다.

## 구현 범위

1. 상단 조작 영역에 `학교명 검색` 입력창과 `찾기` 버튼을 추가한다.
2. OpenStreetMap Nominatim 검색 API를 사용해 학교명을 좌표로 변환한다.
3. 검색 성공 시 지도 중심을 해당 좌표로 이동하고 `학교 위치` 마커를 띄운다.
4. 검색 실패, 빈 검색어, 네트워크 오류는 `aria-live` 상태 문구로 안내한다.
5. 모바일에서는 검색 폼이 현재 버튼 줄을 밀어내지 않도록 최소 폭과 반응형 폭을 제한한다.

## UI 원칙

- 기존 `내 위치 보기`, `내보내기`, `대시보드` 버튼은 그대로 유지한다.
- 검색창은 버튼들과 같은 `top-actions` 안에 두되 별도 카드나 큰 패널을 만들지 않는다.
- placeholder는 동명이교를 줄이기 위해 지역과 학교명을 함께 넣도록 안내한다.
- 결과 목록은 이번 단계에서 만들지 않고, 가장 적합한 결과 1개로 바로 이동한다.

## 데이터/동작

- 검색어는 `school` 키워드를 자동 보강해 학교 검색 의도를 높인다.
- API URL은 `https://nominatim.openstreetmap.org/search`를 사용한다.
- `format=json`, `limit=1`, `countrycodes=kr`을 지정해 한국 학교 검색에 집중한다.
- 응답의 `lat`, `lon`, `display_name`을 사용해 지도 이동과 팝업 문구를 구성한다.

## 검증 계획

- 정적 회귀 테스트로 검색 폼, 상태 영역, 검색 로직의 존재를 확인한다.
- 브라우저 흐름 테스트에서 `fetch`를 mock 처리해 실제 네트워크 없이 검색 입력, 버튼 클릭, 학교 마커 표시를 검증한다.
- 기존 지도 클릭/저장/필터/내보내기 흐름과 모바일 접힘 테스트가 계속 통과하는지 확인한다.
